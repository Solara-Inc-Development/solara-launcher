# Solara V-0.0.12 testing candidate

Built from c1678a7a814bc9b5ad021b2b8be707017dc7b622. This is an acceptance-test candidate, not a stable release. The updater signature is added privately on the Solara build VPS before final staging. Windows publisher signing is not claimed.

Vanilla only. Microsoft sign-in needs an approved Solara application ID; actual login/play, installation and automatic upgrades still need testing. Hosted account services need the separate private deployment.

The NSIS installer and bundled x64 application are separate files, each named solaralauncher.exe. Exact corresponding source, version edits and lockfiles are in source.zip. Dependency notices are bundled in the app.
