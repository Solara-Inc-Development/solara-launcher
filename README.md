# Solara V-0.0.14 testing candidate

Built from fa10bfc8fff6c9ef7877703fe662d26c3ebce3a1. This is an acceptance-test candidate, not a stable release. The updater signature is added privately on the Solara build VPS before final staging. Windows publisher signing is not claimed.

The independent Minecraft core exposes the loaders declared by the preview. Microsoft sign-in needs an approved Solara application ID; actual login/play, installation and automatic upgrades still need testing. Hosted account services use the separate private deployment.

The NSIS installer and bundled x64 application are separate files, each named solaralauncher.exe. Exact corresponding source, version edits and lockfiles are in source.zip. Dependency notices are bundled in the app.
