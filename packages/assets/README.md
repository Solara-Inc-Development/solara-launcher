# Solara assets

This workspace supplies icons and visual assets used by Solara Launcher. Product marks use the existing Solara artwork under `solara/`. The welcome screen and instance icon editor use that same mark.

The icon build tools derive from the upstream asset workspace. Lucide icons retain their original licence; the generated exports are maintained by `pnpm run icons:generate` and checked by `pnpm run icons:validate`.

Retained third-party artwork, source, fonts and icons remain subject to their own licences and notices. See `COPYING.md`, package licence files and the repository's `THIRD_PARTY_NOTICES.md` for provenance. Solara branding does not transfer ownership of third-party content.
